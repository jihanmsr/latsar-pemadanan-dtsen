### Tahapan Kegiatan, Uraian Kegiatan, dan Keterkaitan dengan BerAKHLAK

**Tahapan 1:** Mengembangkan algoritma pemadanan deterministik (kecocokan mutlak)
- **Uraian Kegiatan:** Saya mengembangkan fungsi pencocokan mutlak secara disiplin agar hasil padanan akurat dan dapat dipertanggungjawabkan (**Akuntabel**). Seluruh struktur kode dikelola dengan cermat untuk mencegah kegagalan sistem (**Akuntabel**). Saya menerapkan keahlian pemrograman terbaik (**Kompeten**) serta melakukan *testing* secara mandiri dan profesional (**Kompeten**). Pengembangan ini bertujuan untuk mempercepat proses pencarian data bagi Pemda (**Berorientasi Pelayanan**), sambil terus berinovasi mengikuti tren teknologi terkini (**Adaptif**). Saya senantiasa menjaga sikap saling menghargai saat menerima masukan (**Harmonis**), menunjukkan dedikasi tinggi pada tugas instansi (**Loyal**), serta saling membantu merampungkan fitur bersama rekan tim MTI (**Kolaboratif**).
- **Bukti/Dokumentasi:** Tangkapan layar *source code* pada file `test_matching.js` bagian pencocokan mutlak serta log terminal hasil ujicobanya (menggunakan *dummy data* untuk menjaga kerahasiaan NIK).

**Tahapan 2:** Mengembangkan algoritma probabilistik (*Levenshtein*) menangani *typo*
- **Uraian Kegiatan:** Saya melakukan riset algoritma *Levenshtein* secara proaktif (**Adaptif**) dan mengimplementasikannya secara kreatif untuk menoleransi kesalahan ketik (**Adaptif**). Fitur cerdas ini dibuat semata-mata demi kelancaran dan kepuasan layanan data (**Berorientasi Pelayanan**). Saya menunjukkan penguasaan rekayasa *software* yang mendalam (**Kompeten**) dan menyelesaikan modul koding secara presisi (**Kompeten**). Setiap baris kode ditulis dengan kejujuran logika teknis (**Akuntabel**). Saya bekerja dengan penuh pengabdian melewati jam kerja normal demi progres (*deadline*) (**Loyal**) serta patuh terhadap arahan desain teknis BPS (**Loyal**). Saya menjaga komunikasi yang menyenangkan di ruangan (**Harmonis**) dan bersinergi dengan tim statistik untuk integrasinya (**Kolaboratif**).
- **Bukti/Dokumentasi:** Tangkapan layar algoritma pada file `test_accuracy.py` beserta lampiran file `Hasil_Pemadanan_V3.xlsx` (kolom NIK dan Nama asli penduduk telah disensor/di-*blur* demi keamanan privasi) sebagai log hasil uji coba pemadanan *typo*.

**Tahapan 3:** Menerapkan keamanan data (enkripsi) dan server terisolasi
- **Uraian Kegiatan:** Saya mengonfigurasi keamanan *server* secara ketat dan transparan (**Akuntabel**), serta menjamin kerahasiaan data pribadi (NIK) dengan integritas sangat tinggi (**Akuntabel**). Perlindungan data ini merupakan wujud komitmen keamanan pengguna layanan (**Berorientasi Pelayanan**) dan dedikasi mutlak mematuhi undang-undang privasi negara (**Loyal**). Saya mengadopsi teknik enkripsi termutakhir yang inovatif (**Adaptif**) dan melakukan penyesuaian infrastruktur dengan cepat (**Adaptif**), berbekal ilmu keamanan jaringan yang mumpuni (**Kompeten**). Lingkungan kerja yang kondusif saya pertahankan (**Harmonis**) melalui diskusi teknis dua arah yang terbuka dengan administrator *server* pusat (**Kolaboratif**).
- **Bukti/Dokumentasi:** Tangkapan layar konfigurasi *server* pada file `server.js` dan pengaturan kredensial rahasia pada file `.env` (kredensial disensor/di-*blur*) sebagai bukti keamanan *database* terisolasi.
