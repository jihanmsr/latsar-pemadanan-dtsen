Dokumen Rancangan Skenario Uji (Test Case)

Sistem Informasi Pemadanan Data Terpadu (PAKEWA) - BPS Provinsi Sulawesi Tengah

1. Pengujian Modul - Role Pemda

ID Uji Fitur / Modul Langkah Pengujian (Skenario) Hasil yang Diharapkan (Ekspektasi)
TC-PMD-01 Registrasi Akun Baru Mengisi formulir dengan NIK 16 digit yang valid dan melampirkan file BAST berformat PDF. Sistem menyimpan data ke antrean dengan status "PENDING" dan menunggu verifikasi Admin.
TC-PMD-02 Validasi Keamanan NIK Mencoba mengirimkan formulir dengan NIK hanya 10 digit atau mengandung huruf alfabet. Sistem menolak (Validasi Gagal) dan menampilkan peringatan merah "NIK harus 16 digit angka".
TC-PMD-03 Login Gagal (Password Salah) Memasukkan email terdaftar namun dengan password yang salah sebanyak 3 kali. Sistem menampilkan error "Email atau password salah" dan mencegah akses masuk.
TC-PMD-04 Proteksi Akun Belum Aktif Login menggunakan akun Pemda yang statusnya masih PENDING (belum di-approve Admin). Sistem menolak login dengan pesan "Akun Anda sedang dalam proses verifikasi Admin".

2. Pengujian Modul - Role Internal BPS

ID Uji Fitur / Modul Langkah Pengujian (Skenario) Hasil yang Diharapkan (Ekspektasi)
TC-INT-01 Validasi Ekstensi File Upload file selain .csv atau .xlsx (misalnya .pdf atau .jpg) ke dalam form pemadanan. Tombol upload *disabled* atau muncul peringatan "Format file tidak didukung".
TC-INT-02 Pengecekan Header Kolom Upload Excel yang tidak memiliki kolom bernama "NIK" atau "Nama Lengkap". Sistem menolak file dan memberitahu template tidak sesuai standar.
TC-INT-03 Parsing Data Kosong (Null) Upload Excel dengan baris data kosong di tengah-tengah dokumen. Sistem otomatis membersihkan (melewati) baris kosong tanpa memunculkan error aplikasi.
TC-INT-04 Akurasi Algoritma Levenshtein Mengupload nama dengan sedikit "typo" (misal: "MUHAMMAD" vs "MUHAMAD"). Sistem memberikan skor kemiripan di atas 90% dan memunculkannya sebagai kandidat padan.

3. Pengujian Modul - Role Admin

ID Uji Fitur / Modul Langkah Pengujian (Skenario) Hasil yang Diharapkan (Ekspektasi)
TC-ADM-01 Proteksi Halaman Admin Memaksa masuk ke URL /admin/dashboard menggunakan akun ber-Role "PEMDA". Middleware sistem memblokir akses dan memaksa redirect kembali ke beranda Pemda.
TC-ADM-02 Verifikasi Akun Baru Admin mengklik tombol Setujui pada pendaftar instansi yang berstatus PENDING. Status akun berubah jadi APPROVED dan instansi tersebut bisa melakukan Login.
TC-ADM-03 Stress Test Beban Tinggi Upload file berisi 10.000+ baris NIK sekaligus untuk diproses. Server tetap stabil (tidak timeout) dan proses berjalan di latar belakang secara asinkron.
